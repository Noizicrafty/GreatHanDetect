# GreatHanDetect — русская инструкция

GreatHanDetect — система видеоаналитики производственной безопасности с поддержкой **LinQ TPU**. Сценарии включают контроль курения, защитных касок, страховочных тросов, бега в рабочей зоне и опасных зон. Статус нейросетевой обработки и демонстрационной реализации каждого сценария указан в [основном README](README.md#сценарии-производственной-безопасности).

Актуальная инструкция доступна в основном **[README.md](README.md)**: развёртывание через Docker Compose, автоматическая проверка выполнения модели, обработка веб-камеры, режимы CPU/LinQ, остановка приложения и сохранение журнала.
