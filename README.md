# GreatHanDetect — LinQ TPU Smoking Detection

Experimental adapter for [clyv/smoking-detection](https://github.com/clyv/smoking-detection) and LinQ TPU Framework 2026.9.45. Source is being imported. This adapter is **not yet verified on LinQ TPU hardware**. The repository must not be interpreted as containing trained specialized smoking-action model weights, datasets, or working `.tpu` binaries.

Target: Ubuntu 18.04+, Python 3.12.11, LinQ TPU_H1M SDK. ONNX export can be prepared separately on Windows/Linux.
