# Дополнительные сценарии и демонстрационная связка

Каталог интерфейса показывает основные реализованные конвейеры и три заготовки: каска, сигнальный жилет, падение. Для заготовок прямо указано **«ДЕМО · модель не подключена»**. Ссылка на [PaddleDetection](https://github.com/PaddlePaddle/PaddleDetection) — источник для дальнейшего подбора/переноса моделей, а не утверждение об исполнении его моделей в этом приложении.

В настройках можно включить иллюстрационную связку с подтверждённым событием курения:

```yaml
demo_additional:
  enabled: true
  scenarios: [helmet, vest, fall]
```

У каждого такого события:

- тип начинается с `demo_`, backend — `demo_simulated`;
- версия — `NO_MODEL_EXECUTED_DEMONSTRATION`, confidence — 0;
- отдельный ID и ссылка на исходный эпизод в `episode_id`;
- на кадре и в журнале/уведомлении есть отметка ДЕМО;
- метрики основного правила и задержки реальных уведомлений его не включают.

Одно исходное событие создаёт по одной иллюстрации каждого выбранного сценария. Продолжение/завершение наследует жизненный цикл исходного эпизода, не создавая повторных оповещений. Эта функция служит показу интерфейса и маршрута событий; она не измеряет наличие каски, жилета или падение на кадре. По умолчанию выключена.

Для реального подключения нужны веса выбранной модели, её preprocessing/decoder, проверка конвертации и TPU-исполнения, правило и контрольные данные. После этого демонстрационный провайдер заменяется нейросетевым; происхождение и результаты испытаний сохраняются в manifest и отчёте.
