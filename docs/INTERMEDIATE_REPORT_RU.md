# Промежуточный отчёт — 24.10.2026

## Результат

Реализовано локальное операторское приложение. Полный путь видео → реальный LinQ → человек в зоне → временное подтверждение → кадр → SQLite → уведомление в браузере проверен. Для курения есть программная цепочка и исполняемые модели, но качество TPU-детектора не принято. Каска/жилет/падение только DEMO. Это промежуточный результат, не полная сдача хакатона.

Использованы повторяющиеся публичные фотографии, преобразованные в видео. Частота анализа задана 1 и 0,5 кадра/с соответственно: это не максимум TPU. Четыре события — два человека в двух эпизодах; 102 события длительного прогона не являются независимой выборкой точности. Клиентский инференс включает подготовку, сеть и декодирование. Время накопления окна до подтверждения исключено из display latency.

Длительный прогон выполнен до ускорения опроса UI. После изменения выполнен короткий прогон; внутренний ориентир p95 ≤ 2 с на длительном тесте ещё не подтверждён. ## Данные и обученный checkpoint

Экспорт YOLOv8 от команды: train 12 046, valid 318, test 122, всего 12 486 изображений. Формат корректен. После удаления 158 точных/близких межвыборочных совпадений: 11 897 / 309 / 122. Исходные файлы сохранены, подготовлена отдельная копия. Независимость актёров/сюжетов этим не доказана; визуальные варианты одной сцены остаются внутри test.

Класс `smoking` после проверки аннотаций объединён с cigarette. Итоговые классы: cigarette/person/smoke/vape. В test нет Vape; поз и разметки временных эпизодов в экспорте нет.

Обучение остановлено по запросу. Last checkpoint после 26 эпох, best после 22. Финальная test-оценка и автоматический экспорт прерванного прогона не выполнены. Позже выполнен только инференс last.pt на девяти случайных test-изображениях: [реальные примеры](TRAINED_MODEL_RESULTS_RU.md). Новое обучение не запускалось.

## Ограничения и остаток работ

У TPU YOLO-World выявлена потеря детекций против CPU. Обученный четырёхклассовый детектор не интегрирован в приложение/TPU. Временное событие курения на настоящем видео не принято. Производственные precision/recall, false alarms/hour и сложные условия не измерены.

Локально пройдены 59 unit/integration-тестов. Далее: довести курение на готовых весах, получить реальные ролики, измерить события, повторить длительный тест, проверить чистую поставку моделей и условия использования. [Критерии](ACCEPTANCE_CHECKLIST.md). [Реестр](MODEL_REGISTRY_RU.md).
