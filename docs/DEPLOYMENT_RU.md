# Развёртывание и диагностика

## Установка клиента

Python 3.12 и Git. Из корня проекта: `setup_application_windows.bat` (Windows) или `bash setup_application.sh` (Linux). Скрипты создают `.venv` и устанавливают `requirements/application.txt`. Для правила курения и тестов один раз выполнить `python tools/bootstrap_source.py` в активной `.venv`: он получает зафиксированный upstream-код, но не запускает обучение и не скачивает датасет.

Самый простой проверяемый запуск без моделей:

```bash
python tools/make_app_demo.py
python -m greathan --config assets/demo/replay_config.json --data results/qa
```

Открыть http://127.0.0.1:8080/ и запустить обработку. Это REPLAY, а не модель. Для настоящих детекций следовать разделам ниже.

## Локальный ONNX

Получить модель из [реестра](MODEL_REGISTRY_RU.md), сохранить в соответствующий путь `assets/onnx/`. Указать своё видео в `camera.source` файла `configs/application.yaml`, проверить зону. Пути к локальным ресурсам разрешаются относительно корня репозитория. `assets/input.mp4` — место для вашего файла, он не поставляется.

```bash
python -m greathan --config configs/application.yaml --data results/cpu
```

До видео проверить одиночное изображение:

```bash
python tools/check_model.py --config configs/application.yaml --image /path/to/image.jpg --warmup 2 --requests 20 --out results/cpu_check
```

## Удалённый LinQ

1. Подключить VPN организаторов и проверить доступ к личному Jupyter.
2. Получить из Jupyter `packages/tpu_pycloud_format-0.0.1-py3-none-any.whl` и установить его в клиентскую `.venv` через `python -m pip install /path/to/wheel.whl`.
3. В `configs/danger_zone_linq.yaml` задать видео, зону и серверный `remote_program` из собственной папки `/auto/cache/<team>/`. Локальные пути Windows не являются путями серверного воркера. Значение с именем команды в проверенном шаблоне необходимо заменить для другой команды.
4. Скопировать настоящую `.tpu` на сервер. Хеш `program_sha256` должен соответствовать файлу, не переименованному ONNX.
5. Задать учётные данные **брокера** из примера организаторов, а не VPN-пароль:

```powershell
$env:LINQ_AMQP_USER = '<broker-user>'
$env:LINQ_AMQP_PASSWORD = '<broker-password>'
```

Linux: `export LINQ_AMQP_USER='<broker-user>'`, аналогично пароль. Значения не сохранять в YAML или Git.

```bash
python tools/check_model.py --config configs/danger_zone_linq.yaml --image /path/to/image.jpg --warmup 2 --requests 20 --out results/linq_check
python -m greathan --config configs/danger_zone_linq.yaml --data results/linq
```

Брокер стенда: `10.0.114.30:5672`, exchange `tpu.direct`, routing key `input`. Это адрес из предоставленной схемы, не публичный сервис. Компиляция требует отдельной Linux-среды Python 3.12.11 с SDK; Windows-клиент не компилирует модель.

## Важные настройки

`camera.mode`: `offline` для последовательной обработки файла; `realtime` для воспроизведения по времени с пропуском запоздавших кадров; `live` для сетевого потока. Цифровой индекс USB-камеры не является проверенным live-источником. `analysis_fps` задаёт частоту анализа, не максимум модели. Временная шкала событий основана на PTS источника.

`runtime_config.json` в `--data` имеет приоритет над `--config` при повторном запуске. Для чистой проверки использовать новый каталог `--data`; для сохранения истории — прежний. Одновременно два экземпляра не должны открывать один каталог данных: приложение блокирует это. Для отдельного экземпляра нужны другой порт и каталог.

Консоль слушает только loopback. Встроенной многопользовательской аутентификации нет; текущий сервер не является публичным сервисом. Секретные URL потоков задаются переменными окружения согласно конфигурации источника, не строкой с паролем в сохранённых настройках.

## Типовые проблемы

| Симптом | Проверить |
|---|---|
| Модель/видео не найдены | Получен ли отдельный комплект; пути в YAML; `runtime_config.json` |
| ImportError codec | Wheel установлен тем Python, которым запущено приложение |
| AMQP timeout | VPN, адрес/порт, данные брокера, серверный путь `.tpu`, диагностика воркера |
| Несовпадение тензоров | 416 против 640, имена `images`/`output0`, количество классов и hash |
| Событий нет | Люди действительно в зоне; время подтверждения; min_samples; предмет/поза для курения |
| Frames dropped | Режим realtime пропускает запоздавшие кадры; смотреть фактический FPS и сеть |
| Изменилась конфигурация, но стартует старая | Приоритет сохранённого runtime_config в прежнем `--data` |
| TPU работает, но не видит сигарету | Известное ухудшение YOLO-World после PTQ; сравнить тот же кадр с CPU |

При ошибке инференса сцена не объявляется безопасной: ошибка попадает в диагностику. Не принимать отсутствие результата за отсутствие нарушения.
