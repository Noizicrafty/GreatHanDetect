# Приёмка прототипа

Отметка относится только к указанному объёму. Весь хакатон пока не закрыт.

## Подтверждено

- [x] Экспорт и ONNX-инференс YOLOv8n people, YOLO11n-Pose, YOLO-World.
- [x] Компиляция трёх программ TPU_H1M / O1 через SDK 2026.9.45.
- [x] Реальное удалённое AMQP-исполнение, проверка имён/форм выходов.
- [x] Сравнение CPU/TPU на одинаковых изображениях; ухудшение YOLO-World зафиксировано.
- [x] Зона: видео → LinQ → трек → подтверждение → доказательство → журнал → UI.
- [x] Проверены отдельные эпизоды, короткое перекрытие, потеря трека, ошибки.
- [x] Фильтры, решения оператора, CSV и восстановление истории проверены.
- [x] Измерены клиентские тайминги и проведён 10-минутный прогон повторяемых сцен.
- [x] Аудит датасета без изменения исходников; сохранён checkpoint после 26 эпох.
- [x] Выполнены реальные тестовые предсказания checkpoint.
- [x] 59 автоматических тестов локально пройдены.
- [x] Дополнительные сценарии явно DEMO и исключены из реальных метрик.

## До сдачи

- [ ] Исправить качество курения после PTQ либо принять иной проверенный вариант вычислений.
- [ ] Подключить финальный детектор с точными классами и формами, а не только сохранить веса.
- [ ] Проверить репрезентативную калибровку на train; test не использовать для настройки.
- [ ] Получить реальные положительные/отрицательные ролики и разметку эпизодов.
- [ ] Измерить event precision/recall, false alarms/hour и задержку на независимом видео.
- [ ] Проверить освещение, компрессию, мелкие объекты, похожие действия, перекрытия.
- [ ] Повторить длительный тест после последних изменений UI; короткий прогон не доказывает p95 ≤ 2 с в длительном.
- [ ] Проверить чистую установку с отдельным комплектом моделей/программ.
- [ ] Завершить проверку условий использования сторонних материалов.
- [ ] Подготовить итоговые демонстрацию и отчёт с разделением TPU, CPU и DEMO.

Прямой `pytpu.Device.list_devices()` не требуется клиенту удалённого AMQP-сервиса. 30 FPS и промышленная готовность не заявлены. Новое обучение не является условием завершения текущего этапа.
