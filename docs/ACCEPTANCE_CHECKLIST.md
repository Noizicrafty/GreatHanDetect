# Приёмочные критерии

- [ ] Обе ONNX-сети проходят проверку ONNX Runtime.
- [ ] Сохранены корректные боксы и ключевые точки на видео.
- [ ] PTQ-калибровка выполнена на репрезентативных CCTV-кадрах.
- [ ] Обе модели собраны через TPU_H1M / O1.
- [ ] Созданы и проверены настоящие файлы .tpu.
- [ ] Устройство обнаружено через pytpu.Device.list_devices().
- [ ] Проверены формы и имена выходных тензоров LinQ.
- [ ] Сопоставлены CPU ONNX и TPU результаты на одинаковых кадрах.
- [ ] Измерены FPS, recall событий, false alarms/hour и задержки.
- [ ] Протестированы слабое освещение, компрессия и дальний план.
- [ ] Проверены лицензии upstream/Ultralytics/датасетов.
