# Реальная работа модели после 26 эпох

Использован YOLOv8n checkpoint `last.pt`: внутреннее `epoch=25`, то есть **26 завершённых эпох**. Рядом сохранён `best.pt` после 22 эпох; иллюстрации построены именно по last. Это веса локального прерванного прогона, не YOLO-World и не ранее скомпилированная person-модель.

Инференс: PyTorch CUDA, imgsz=640, conf=0.25, NMS IoU=0.7. Девять изображений взяты из sorted test list через `random.Random(42).sample(..., 9)` до просмотра предсказаний. Все девять показаны, включая пропуски. На втором листе кроп выбирается по GT; рамки и числа остаются исключительно выходами модели. Увеличение выполнено после инференса. Обучение не возобновлялось.

## Воспроизведение

Получить отдельно checkpoint и подготовленные test-изображения со списком путей. Установить зависимости `requirements/train.txt` в отдельное окружение с PyTorch. Это окружение используется для чтения `.pt`, обучение не требуется.

```bash
python tools/illustrate_checkpoint.py --checkpoint /path/to/last.pt --test-list /path/to/test.txt --out results/checkpoint_examples
```

Скрипт проверяет число эпох из checkpoint, запускает только predict и сохраняет изображения и provenance. В Git не включены веса и весь датасет. SHA-256 checkpoint приведён в [реестре](MODEL_REGISTRY_RU.md).
